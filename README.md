## Run from this folder

Python 3.12 was used for validation. Install requirements into a virtual environment.

    python -m pip install -r requirements.txt
    python scripts/run_all.py

Or run the individual steps:

    python scripts/run_structure.py
    python scripts/run_cluster_checks.py
    python scripts/run_models.py
    python scripts/draw_pca_figure.py
    python scripts/check_against_manuscript.py

Optional 600-dpi figure regeneration (after the analyses):

    python scripts/run_all.py --figures

Or run the individual figure scripts:

    python scripts/draw_survey_figures.py
    python scripts/draw_cluster_figure.py
    python scripts/draw_pca_figure.py
    python scripts/draw_model_figures.py

Numerical outputs are in outputs/tables. Figures 2-12 and an alternative
Figure 1 can be regenerated by these scripts. The currently embedded Figure 1
is also included as an existing asset. Figure 7 has a corrected 600-dpi replacement:
79.9% is the cumulative variance of eight components (nine explain 82.7%).
Panel d reports signed eigenvector coefficients, rather than loading magnitudes.

## Corrections and limits

- Overall satisfaction is a separate questionnaire item; six attribute scores
  and five facility ratings are predictors. Same-survey common-method bias remains.
- Predictive R2 is 1-SSE/SST, not squared Pearson correlation.
- Original split: NumPy RandomState(42), 252 training and 109 previously inspected
  holdout respondents. Train-only five-fold MAE selects among four models.
- Retrospective five-by-five nested CV evaluates the revised selection procedure;
  it is not a fresh independent validation sample.
- Conditional paired bootstrap: 1,000 resamples, fixed predictions. It excludes
  refitting, selection and park-nesting uncertainty. Unsupported interval coverage
  and residual autocorrelation analyses are absent.
- Ordered-logit sensitivity analysis and six-attribute mean baseline are included.
- K-means uses all 361 respondents and 17 standardized rating items. Group labels
  describe lower/higher ratings. Formal background-variable tests are descriptive.
- EFA retains one unrotated ML factor, with 2,000 within-item permutation datasets,
  KMO, Bartlett, full loadings/communalities, and block alpha coefficients.
- The recommendation-score anomaly remains unexplained. The retained raw variable
  is audited only; it is not used in the revised satisfaction models.
- There are no park identifiers. Response rate, excluded-record reasons, consent
  interface and geographic IP screening cannot be reconstructed from this dataset.

The included numerically coded workbook is identical in cell values to the
existing released data. No ethics letter, names, contact details, manuscript,
reviewer correspondence or local machine paths are included in the release data.

## Validation and provenance

`requirements-validated.txt` records the environment used for validation.
`validation/numerical_validation.json` records 41 numerical checks and five
structural assertions. The numerical checker compares generated tables with
specified reference claims; it does not read or modify a Word document.
`validation/file_sha256.json` contains release file checksums, excluding itself
and Git metadata. See `outputs/README.md` for the figure map and snapshot notes.
