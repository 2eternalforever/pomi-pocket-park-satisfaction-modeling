# Revised numerical outputs and figures

`tables/` contains model metrics, predictions, validation folds, bootstrap samples,
ordinal sensitivity results, factor loadings, parallel-analysis results, PCA
results, clustering summaries, and data audits.

The provided figure scripts generate PNGs with 600-dpi metadata:

| Script | Figures |
|---|---|
| `draw_survey_figures.py` | 3-6 |
| `draw_pca_figure.py` | 7 (corrected) |
| `draw_cluster_figure.py` | 8 |
| `draw_model_figures.py` | 1 (alternative), 2, 9-12 |

Files named `*_preview.png` are smaller previews. `Figure_1_current_manuscript.png`
is an existing manuscript asset, not an image regenerated by these scripts. Use
`Figure_7_corrected_600dpi.png` for the revised PCA figure; the superseded embedded
Figure 7 is excluded from this release.

`validation/figure_comparison.json` records comparisons with a local manuscript
snapshot on 19 October 2026. It does not check future manuscript edits.
`check_against_manuscript.py` checks specified numerical reference claims against
generated tables; it does not read or edit a Word document.

After regenerating outputs, file hashes can differ because of software versions,
rendering, or serialization; review numerical checks as well as hashes.
